
# Analisis Komparatif Platform

## 1. Perbandingan Platform Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | C#, Java, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, aplikasi berjalan melalui browser dan berkomunikasi dengan server | Aplikasi diinstal pada komputer dan dapat memproses data secara lokal atau melalui server | Aplikasi berjalan pada smartphone dan dapat menggunakan layanan lokal maupun server |
| Cara distribusi | Diakses melalui browser menggunakan URL | Diunduh atau diinstal melalui installer atau toko aplikasi | Diunduh melalui toko aplikasi seperti Google Play Store atau Apple App Store |
| Keunggulan | Mudah diakses, tidak selalu perlu instalasi, dan pembaruan dapat dilakukan di server | Dapat memanfaatkan sumber daya komputer dan memiliki akses lebih luas ke sistem operasi | Praktis, portabel, dan dapat memanfaatkan fitur perangkat seperti kamera serta GPS |
| Keterbatasan | Bergantung pada browser dan untuk banyak fitur memerlukan koneksi internet | Perlu instalasi dan kompatibilitas dengan sistem operasi perlu diperhatikan | Memiliki keterbatasan ukuran layar, baterai, dan perbedaan perangkat |
| Contoh aplikasi | Google Docs, Gmail, Trello | Microsoft Word, Visual Studio Code, VLC Media Player | WhatsApp, Google Maps, Instagram |

## 3. Refleksi

Platform yang paling menarik bagi saya untuk dipelajari adalah platform web. Menurut saya, platform web memiliki keunggulan karena aplikasi dapat diakses melalui browser tanpa harus selalu melakukan instalasi pada perangkat pengguna. Selain itu, pengembangan web memungkinkan penggunaan berbagai teknologi seperti HTML, CSS, dan JavaScript untuk membangun aplikasi yang interaktif. Saya ingin mempelajari lebih lanjut bagaimana sebuah aplikasi web dibuat, dihubungkan dengan server, dan digunakan oleh banyak pengguna.

Dalam proses persiapan lingkungan pengembangan, tantangan yang perlu diperhatikan adalah memastikan setiap tools terinstal dengan benar dan dapat dijalankan melalui terminal. Git, Node.js, NPM, dan Java JDK memiliki fungsi yang berbeda, sehingga saya perlu memahami kegunaan masing-masing tools. Saya melakukan pengecekan versi melalui Command Prompt untuk memastikan instalasi berjalan dengan baik. Android Studio juga perlu dipersiapkan sebagai lingkungan pengembangan aplikasi Android.

Untuk mengatasi tantangan tersebut, saya akan mempelajari dokumentasi resmi dari setiap tools, mengikuti panduan instalasi secara bertahap, dan mencoba kembali perintah terminal apabila terjadi kesalahan. Saya juga akan membiasakan diri menggunakan Visual Studio Code dan GitHub untuk mengelola file serta menyimpan perubahan kode. Dengan latihan secara rutin, saya berharap dapat memahami proses pengembangan aplikasi pada platform web, desktop, dan mobile dengan lebih baik.
